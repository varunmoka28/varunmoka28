# Varun Moka

I build with Claude Code by directing agents. Most of what I make is the setup around them: small mods for the terminal, hooks that stop a bad delete, rules for how an agent should work, and ways to run several agents side by side.

## moka-harness

[moka-harness](https://github.com/varunmoka28/moka-harness) is that setup as one plugin marketplace. Some of it I wrote and some I adapted. Most of it is other people's plugins and skills, each pinned to one commit and credited to its author. It has been checked on macOS only.

```
claude plugin marketplace add varunmoka28/moka-harness
claude plugin install core@moka-harness
```

Before installing anything, read [how far to trust this](https://github.com/varunmoka28/moka-harness#how-far-to-trust-this).

Something broken on your machine? Open an [issue](https://github.com/varunmoka28/moka-harness/issues).
